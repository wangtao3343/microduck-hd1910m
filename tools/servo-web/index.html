校准 一颗一颗来：摆好一颗，校一颗

校准只碰选中的这一颗，别的舵机照常撑着，所以不用把所有颗同时摆到位 —— 摆好一颗校一颗就行。 校准就是让这颗「现在的位置」读成基准值（0x0B，舵机自己存），关节不动。
官方折叠（默认）把鸭子折好趴稳，不用悬空扶；每颗该摆成什么样，选完舵机这行会写。 零位 2048 得把鸭子悬空扶成腿伸直、脚板垂直；存的姿态 靠那个姿态自己的机械接触定位。
点按钮先弹确认框，列出这一颗「现在 → 写成、差几度」，差 30° 以上再确认一次： 一整轮校过的颗共用一份备份，撤销整轮能一次退回起点（不用一颗颗退）；换基准就算新的一轮。
